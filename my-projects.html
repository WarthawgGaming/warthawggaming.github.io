AutoHopper

Minecraft Java Edition Plugin

AutoHopper is a custom Minecraft plugin that lets a player right-click a hopper with a stick, then crouch on that hopper to empty their inventory into it.

  • Only empties the player inventory.
  • Does not remove armor.
  • Does not remove hotbar items.
  • Designed for survival server convenience.

Download autohopper-1.0.jar
